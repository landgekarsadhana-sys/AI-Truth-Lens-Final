AI TRUTH LENS - FINAL ONE-CLICK DEMO

1. Put your Gemini API key in a file named .env in this same folder:
   GEMINI_API_KEY=YOUR_ACTUAL_API_KEY

2. Double-click RUN_AI_TRUTH_LENS.bat.

3. The launcher creates/repairs .venv, installs dependencies, starts Flask,
   and opens http://127.0.0.1:5000.

4. Upload JPG/JPEG/PNG/WEBP and click Analyze Image.

Important:
- Do not share your API key.
- Do not delete your .env file.
- If Gemini is temporarily unavailable, the app will not invent a score.
